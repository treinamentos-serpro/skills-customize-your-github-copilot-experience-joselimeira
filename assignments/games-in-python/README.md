# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique strings, loops, condicionais, entrada de dados e seleção aleatória em Python construindo um jogo da Forca interativo.

## 📝 Tarefas

### 🛠️ Preparar o Estado do Jogo

#### Descrição
Complete a configuração inicial do jogo usando a lista de palavras fornecida no código inicial.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra secreta da lista `words`.
- Inicializar uma estrutura para armazenar as letras já adivinhadas.
- Definir o número máximo de tentativas incorretas e inicializar o contador correspondente.

### 🛠️ Implementar o Loop de Palpites

#### Descrição
Implemente o loop principal para que o jogador possa adivinhar letras e acompanhar seu progresso até vencer ou perder.

#### Requisitos
O programa concluído deve:

- Exibir o progresso atual da palavra usando letras reveladas e espaços ou sublinhados para letras ainda não descobertas.
- Solicitar ao jogador um palpite de letra e atualizar as letras adivinhadas.
- Reduzir o número de tentativas restantes quando o palpite estiver incorreto.
- Encerrar o jogo quando a palavra for completamente adivinhada ou quando não houver mais tentativas.
- Exibir uma mensagem indicando vitória ou derrota e revelar a palavra secreta ao final.
